# Бот-администратор для групп Telegram

Следит за порядком в группе вместо модератора.

## Возможности
- **Капча для новичков** — кнопка «Я не бот», иначе удаление из группы через 2 минуты (защита от спам-ботов)
- **Приветствие** с правилами, удаление сообщений «вступил / покинул группу»
- **Удаление ссылок** (кроме разрешённых сайтов) и **мата** с предупреждениями
- **Мут** после 3 предупреждений, **антифлуд** — мут за частые сообщения
- **Команды для админов** ответом на сообщение: `/warn`, `/mute 30`, `/unmute`, `/ban`, `/unban`; для всех — `/rules`
- Админов бот не трогает; сообщения бота удаляются сами, чтобы не засорять чат
- Все настройки (правила, слова, лимиты, время) — в `config.py`

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и впишите токен
3. Добавьте бота в группу и сделайте администратором с правами «Удаление сообщений» и «Блокировка пользователей»
4. `python bot.py`

Технологии: Python, pyTelegramBotAPI
